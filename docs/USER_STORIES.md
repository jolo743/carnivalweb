## Sprint Backlog

### Sprint 1 (Días 1–4) — Estructura y lógica base
- Setup del repo: ramas, estructura de carpetas, landing page básica
- Cada jugador: HTML semántico de su juego + pantalla de inicio con nombre
- Cada jugador: lógica JS principal del juego (sin animaciones)
- Objetivo: todos los juegos son jugables (aunque sean feos)

### Sprint 2 (Días 5–8) — Diseño, animaciones y pulido
- CSS completo: diseño mobile-first, variables, responsive
- Animaciones y transiciones CSS
- Efectos de sonido
- Temporizadores y sistemas de puntuación
- Extras si queda tiempo
- Preparar presentación
